# Metrolist (Fork)

This project is a fork of [Metrolist](https://github.com/MetrolistGroup/Metrolist) starting from **v13.6.1**.

---Current Version 13.6.1-c

## 🚀 Changes & Improvements

### **Android Auto**
* **Updated Support:** Improved overall stability and feature set for Android Auto.
* **Playlists:** Added support for displaying playlists directly within the Android Auto interface.
* **Customization:** Added new configuration options under `Settings > Android Auto` to customize which tabs are displayed.
* **Queue Fix:** Fixed a crash where the queue button would break when loading playlists larger than 4,000 songs.
* **Performance:** Resolved a memory leak that previously caused crashes while using Android Auto.

### **Navigation & Tabs**
* **Mixes:** Moved to a dedicated, separate tab *(Note: Currently has minimal testing)*.
* **New Releases:** Added a dedicated "New Releases" tab.
* **Discover:** Added a "Discover" tab *(Note: Experimental / not working correctly at this time)*.
* **Playlists:** Unchanged and functioning as standard.

### **Bug Fixes & Library Sync**
* **Playlist Sync:** Resolved an issue where long playlists would truncate or omit songs during library synchronization.
