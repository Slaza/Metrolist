# Metrolist

A YouTube Music client for Android.

> [!NOTE]
> Upstream Metrolist is not currently accepting new feature requests. This fork is where I will make my own feature additions and app changes.

> [!WARNING]
> If YouTube Music is unavailable in your region, the app requires a VPN or proxy connected to a supported region.
